# SMART SHOP ONLINE SHOPPING

A premium, modern and mobile-friendly online shopping store.

## Brand Colors
- Navy Blue
- White
- Gold

## Languages
- English
- Roman Urdu
- Urdu with RTL support

## Customer Features
- Customer signup and login
- Welcome Back greeting
- Product search and categories
- Shopping cart and wishlist
- Cash on Delivery
- WhatsApp ordering
- Send product images through WhatsApp
- Order history

## Admin Panel
- Secure admin login
- Upload product images
- Add, edit and delete products
- Set product prices and stock
- Manage orders
- Manage delivery charges

## Future Features
- Markaz integration
- JazzCash and Easypaisa
- Automatic order management
